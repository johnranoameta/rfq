RFQ Assistant — UI Redesign

Five production-ready directions for the RFQ analysis tool. All share one restrained light-neutral palette; each is a radically different information architecture. Same data across all five (4 cases, incl. a 46-gap stress case) so they're judged on form.

4 cases · A (2 gaps) · B (4) · C (14) · D (46, multi-part) — open any file and switch cases + tabs.

01
Enterprise SaaS

Atlas

Top bar + icon rail, airy cards, generous whitespace. Linear/Stripe-dashboard feel.

Gaps → accordion grouped by severity
02
Data Workstation

Console

Dense, table-first, tabular numerics. Maximum information per screen — light, not dark.

Gaps → sortable table, rows expand in place
03
Document / Report

Dossier

Reads like a printed engineering review memo. Serif headings, sticky table-of-contents.

Gaps → numbered report sections, collapsible
04
Master-Detail Inbox

Triage

Two-pane email-client. List + detail — the direct answer to "hundreds of gaps."

Gaps → list/detail split, no accordion
05
Guided Dashboard

Cockpit

Workflow spine + KPI gauges. Decision-support, status at a glance, progressive disclosure.

Gaps → severity buckets (accordion of groups)
06
Modern Minimal

Nova

Near-monochrome, airy, soft surfaces, one muted indigo accent. Clean modern-product feel.

Gaps → severity buckets, airy accordion
07
Sleek · typeui.sh

Sleek

Deep-navy brand, pill controls, 24px radii, soft shadows — and automatic dark mode.

Gaps → severity buckets, pill chips
How to evaluate. Each handles the 46-gap Case D differently — that's the real test:
  • Atlas / Cockpit — grouping (severity / sub-part) keeps the list collapsible & scannable.
  • Console — density + sort + sticky headers fit it all in one tight table.
  • Dossier — per-sub-part report sections with a summary table on top.
  • Triage — master-detail means volume never overwhelms; you work the list one item at a time.
